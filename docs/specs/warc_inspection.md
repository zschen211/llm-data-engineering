# WARC Inspection

## 背景说明
当前我在 data 目录下存放了一些 warc.gz 压缩文件，需要一个脚本来查阅这些压缩文件，帮助我梳理数据文件中的内容

## 实现路径
### WARCIO cli
1. 在 cli 文件夹下实现一个 warc 内容阅读脚本，帮助我对 warc 文件内容进行分析，阅读器使用 warcio 工具包实现
### 评估标准
1. warcio cli 需要具备阅读文件内容的能力，默认可查看从头开始计数的一部分内容，并支持指定 offset 和范围进行阅读
2. warcio cli 可以帮助我查看数据中的统计信息，比如有多少个 url 路径
